# 논문 카드 스키마 (`content/papers/P??.json`)

논문 10편을 **같은 틀**로 큐레이션하기 위한 데이터 규격이다. 대시보드의 「논문 서가」와 DOCX 보고서의 선행연구 절이 모두 이 파일에서 만들어진다. 분석 에이전트·검증 에이전트·빌드 스크립트가 공유하는 유일한 인터페이스이므로, 키 이름을 바꾸려면 이 문서와 `build/validate_cards.py`를 함께 고친다.

## 공통 규칙

1. **쪽수 앵커(`src`)** — 모든 서술 항목에 붙인다. 형식은 `p.N` 또는 `p.N-M`, 뒤에 위치 설명을 덧붙일 수 있다(예: `p.6 Table 2`, `p.3 §2.1`). 쪽수는 학술지 쪽수가 아니라 **PDF 쪽 번호(1부터)** 이며 `papers/txt/P??.txt`의 `===== [P?? p.N/총쪽] =====` 표지와 일치해야 한다.
2. **원문 인용(`quote`)** — 핵심 구절만, **영어 15단어(한국어 15어절) 이내**. 그보다 긴 내용은 `paraphrase_ko`에 의역하고 쪽수로 가리킨다. 저작권 자료를 옮겨 적지 않는다.
3. **수치** — 원문 표기 그대로(`0.66`, `34.7%`, `N = 44`). 단위(%, %p, 상대 개선율)를 반드시 구분한다. 계산해서 얻은 값은 `value`에 `(재계산)`을 붙이고 산식을 `what`에 적는다.
4. **모르는 것은 모른다고 쓴다** — 원문에 없는 서지사항·수치는 추정하지 않고 `null` 또는 `"원문 미표기"`로 둔다.
5. **언어** — 서술은 한국어. 전문 용어는 첫 등장 시 원어를 병기한다.
6. **JSON** — UTF-8, 들여쓰기 2칸, 주석 없음.

## 최상위 키

| 키 | 형식 | 설명 |
|---|---|---|
| `id` | `"P01"`…`"P10"` | 논문 ID |
| `role` | `core` \| `adjacent` \| `subdata` | 핵심 계승 / 인접·방법 / 하위 데이터 참고 |
| `short` | 문자열 | 본문 인용형. 예: `Cho & Kwon (2026)` |
| `title`, `title_ko` | 문자열 | 원제, 한국어 번역 제목 |
| `citation` | 객체 | `apa`, `year`, `venue`, `status`(`published`\|`in_press`\|`preprint`\|`proceedings`), `doi`, `url`, `bib_notes` |
| `one_line` | 문자열 | 한 문장 요약(80자 안팎) |
| `w5h1` | 객체 | 6하원칙 카드. 아래 참조 |
| `layers` | 객체 | 단어·문장·문단·맥락 4층 분석. 아래 참조 |
| `design` | 객체 | 실험 설계 요약. 아래 참조 |
| `stimulus_examples` | 배열 | 논문이 제시한 자극 예문 `{ko, gloss, condition, src}` (로마자 표기는 한글로 복원) |
| `key_numbers` | 배열 | `{what, value, src}` — 재현·비교 대상이 되는 핵심 수치 |
| `limitations` | 배열 | `{text_ko, stated_by: "author"\|"us", src}` |
| `successor_hooks` | 배열 | 계승 지점. 아래 참조 |
| `open_materials` | 배열 | `{what, url}` — 공개 자극·코드·데이터 |
| `prior_analysis_check` | 객체 | 기존 분석과의 대조 결과 `{source, agreements, discrepancies[]}` |
| `verification` | 객체 | `{status: "draft"\|"verified"\|"corrected", by, notes[]}` — 검증 에이전트만 고친다 |

## `w5h1` — 6하원칙 카드

여섯 키 `who`, `when`, `where`, `what`, `how`, `why` 각각이 `{headline, items[]}` 이다. `headline`은 한 문장, `items[]`는 `{label, text, src}`.

| 키 | 반드시 답할 것 |
|---|---|
| `who` | 저자·소속 / **누구를 실험했나**(모델 이름·규모, 인간 참여자 수·속성) |
| `when` | 발표 시점·게재 상태 / **실험한 모델의 세대**(출시 연도) — 결과의 유효 기간을 판단하는 근거 |
| `where` | 발표처 / 데이터·코퍼스 출처 / 공개 자료 위치 |
| `what` | 연구 질문 / 핵심 주장 / 주요 결과 |
| `how` | 자극 설계 / 측정 지표 / 통계 분석 |
| `why` | 문제의식 / 저자가 밝힌 의의와 한계 / **우리 후속 연구가 이 논문에서 이어받을 것** |

## `layers` — 4층 분석

| 층 | 항목 형식 | 최소 개수 (core·adjacent / subdata) |
|---|---|---|
| `word` | `{term, gloss_ko, definition, note, src}` — 핵심 용어의 조작적 정의, 조건 라벨, 헤지·평가 어휘, 다른 논문과 뜻이 갈리는 용어 | 8 / 4 |
| `sentence` | `{kind, quote, paraphrase_ko, numbers[], src}` — `kind`는 `claim`\|`hypothesis`\|`result`\|`method`\|`limitation`\|`future_work` | 12 / 6 |
| `paragraph` | `{section, move, summary_ko, src}` — `move`는 `background`\|`gap`\|`claim`\|`method`\|`evidence`\|`interpretation`\|`limitation`\|`future_work` | 8 / 4 |
| `context` | `{axis, text_ko, related[], src}` — `axis`는 `lineage`(인용 계보)\|`theory`(이론적 입장)\|`model_generation`\|`agreement`(타 논문과 합의)\|`conflict`(불일치)\|`field`(분야·독자) | 5 / 3 |

`subdata`(KITE·KoBALT)는 논문 전체가 아니라 **경어·높임·화용 관련 하위 항목**에 집중한다.

## `design`

`{phenomenon, stimuli, conditions[], n_items, measures[], models[], humans, stats, is_factorial}` — `is_factorial`에는 요인설계 여부와 요인·수준을 적는다(예: `"2×2: 주어 지위[높임/비높임] × -시-[유/무]"`, 해당 없으면 `"아님 — 단일 요인 4수준"`).

## `successor_hooks` — 계승 지점

`{id, hook_ko, basis_ko, kind, src}`. `id`는 `P02-H1` 형식. `kind`는 다음 중 하나.

| kind | 뜻 |
|---|---|
| `author_future_work` | 저자가 후속 과제로 직접 밝힘 |
| `unresolved_confound` | 설계상 분리되지 않은 교란 요인 |
| `untested_condition` | 검증되지 않은 조건·현상 |
| `method_gap` | 측정·프롬프트·통계 방법의 공백 |
| `model_generation` | 실험 모델이 구세대라 최신 상용 모델에서 재검증 필요 |

core 논문은 3개 이상, 나머지는 2개 이상.
