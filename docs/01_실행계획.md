# 한국어 경어법 × LLM 후속 연구 설계 — 실행계획

> **작업자에게:** 이 계획은 작업 ID 단위로 실행한다. 각 작업은 ① 산출물 파일이 있고 ② 검증을 통과했고 ③ `인수인계서.md`의 작업 대장이 갱신됐고 ④ 커밋됐을 때만 "완료"다. 커밋 메시지는 `[P1-03] …`처럼 작업 ID로 시작한다.

**목표:** 선행 논문 10편을 계승하는 2×2 요인설계 후속 연구를 설계하고, DOCX 보고서 1벌 + 6하원칙 대시보드(HTML) + 인수인계서로 납품한다.

**구조:** 사고·기획은 Fable, 단순 코드는 Opus가 맡고 메인 세션(Fable)이 지휘한다. 모든 내용은 `content/`의 구조화 데이터에 먼저 쓰고, 빌드 스크립트가 거기서 DOCX와 HTML을 만든다.

**도구:** Python 3.13(표준 라이브러리 + python-docx 1.2), poppler(`pdftotext`, `pdfinfo`), git, gh. 외부 CDN 없이 단일 HTML 파일.

**근거 문서:** `docs/00_전략서.md`(무엇을 왜), `docs/02_논문카드-스키마.md`(논문 카드 규격)

## 전역 제약

- 논문에 대한 모든 서술에 PDF 쪽수 앵커 `p.N`을 붙인다. 원문 인용은 15단어 이내.
- 수치는 원문 표기 그대로, 단위(%·%p·상대 개선율)를 구분한다. 원문에 없는 것은 추정하지 않는다.
- 생성자 ≠ 검증자. 검증 결과는 인수인계서 §5에 기록한다.
- 모든 실험은 2×2(요인 2 × 수준 2). 평가는 7점 Likert와 이해 문항. 핵심 설계에 surprisal·미세조정·로컬 GPU를 넣지 않는다.
- 모델 정보(모델 ID·가격·API 제공 여부)는 공식 문서 URL과 확인일(YYYY-MM-DD)을 함께 적는다.
- 참고문헌은 APA 7 + `[n]` 번호 + DOI 전체 URL(없으면 원문 URL과 접속일). DOI는 실제 연결을 확인하고 미확인은 표시한다.
- `papers/`, `reference/`는 커밋하지 않는다. 인수인계서는 메인 세션만 고친다.
- 서술 언어는 한국어. 대시보드는 외부 리소스 없이 열리는 단일 HTML 파일, 라이트·다크 모두 지원, 휴대폰 폭에서 가로 스크롤 없음.
