## 2. 대시보드 (`dashboard/index.html`)

### 2.1 형식 원칙

- **단일 HTML 파일.** 데이터(JSON·CSV)는 빌드 때 `<script type="application/json">`으로 넣는다. 외부 CSS·JS·글꼴을 불러오지 않는다(오프라인·GitHub 파일 보기에서도 열려야 한다).
- **라이트·다크 모두 지원.** 색은 `:root` 토큰으로 정의하고 `@media (prefers-color-scheme: dark)`에서 다시 정의한다. 헤더에 수동 전환 버튼(라이트/다크/시스템)을 두고 `data-theme`으로 덮어쓴다.
- **휴대폰 폭(375px)에서 가로 스크롤 없음.** 넓은 표는 표 자체만 가로 스크롤되게 감싼다. 탭 막대는 좁은 화면에서 가로로 스크롤한다.
- **탭 상태는 URL 해시로**(`#why`, `#paper-P02`) 저장해 링크를 공유할 수 있게 한다.
- 글꼴은 시스템 한글 글꼴 스택(`-apple-system, "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif`). 수치는 `font-variant-numeric: tabular-nums`.
- 모든 논문 서술 옆에 쪽수 앵커(`P02 p.4`)를 작은 칩으로 붙인다. 참고문헌 번호 `[n]`은 참고문헌 탭의 항목으로 이동하고, 그 항목의 DOI는 클릭하면 원문으로 간다.

### 3.2 형식

- A4 세로, 여백 상하 25mm·좌우 20mm. 본문 10.5pt, 제목 계층 3단(장 16pt / 절 13pt / 항 11pt). 한글 글꼴은 맑은 고딕(Word 기본 설치), 영문은 같은 글꼴로 통일.
- 목차 필드(Word에서 업데이트), 머리글에 보고서 제목, 바닥글에 쪽 번호.
- 표는 머리 행 음영과 반복, 넓은 표(자극 목록)는 가로 방향 구역으로.
- 참고문헌의 DOI는 클릭 가능한 하이퍼링크. 본문 인용은 저자-연도 + [n].
- 파일 크기가 커지지 않게 그림은 넣지 않는다(허가자 거리 축은 표로 표현).
